# 💎 학돌함

학교를 돌리는 작은 도구들을 한곳에서 빠르게 찾는 **학돌랩 통합 포털**입니다.

## 바로가기

- 학돌함: https://sen-vip.github.io/hakdolham/
- GitHub: https://github.com/sen-vip/hakdolham

## v0.2.1 업데이트

### 학돌함 역할 재정의

기존의 특정 핵심도구 중심 구조에서 벗어나, **학돌랩에서 만든 학교 업무 도구를 업무 상황에 따라 찾는 통합 포털**로 개편했습니다.

### 대표 도구

상단에는 현재 자주 꺼내 쓰기 좋은 6개 도구를 배치했습니다.

- 학돌 월별업무판
- 학돌 루틴집
- 공문핏
- 경력증명 자동화 `NEW`
- 계약 콕검
- 학교카드맵

### 업무별 전체 도구

도구를 다음 기준으로 다시 분류했습니다.

- 일정·루틴
- 문서 자동화
- 계약·지출
- 점검·확인
- 학교생활
- 실험실

### 이번에 함께 반영한 내용

- 우리학교 키박스 완전 제거
- 키박스 전용 핵심도구 카테고리와 강조 CSS 제거
- `학돌 월별 필수업무` → `학돌 월별업무판`으로 명칭 정리
- `학돌 루틴` → `학돌 루틴집`으로 명칭 정리
- `우리학교 생활달력` → `오늘학교`로 명칭 정리
- 경력증명 자동화 추가
- 전국 학사일정 추가
- 교육청 법카맵 바로가기 정리
- 검색 대상에 새 도구와 새 키워드 반영
- 기존 즐겨찾기에 삭제된 도구가 남아 있어도 자동 제외
- `나의 책상` → `오늘의 작은 책상`으로 정리하고 도구 목록 아래로 배치
- 데스크톱 3열 / 태블릿 2열 / 모바일 1열 반응형 유지
- 기존 보라·인디고 기반 학돌함 컬러 유지
- 품샷 설명 문구 보강 및 `비공개` 상태 표시
- `세콤매니저용 초과근무 변환기`로 명칭·설명 정리
- 세콤매니저 상태를 `블로그 업로드 준비중`으로 표시
- 링크가 없는 도구도 카드에서 설명 문구가 보이도록 개선

## 주요 기능

- 도구명·업무명·키워드 통합 검색
- Enter로 검색 결과 첫 번째 도구 바로 열기
- 업무별 도구 분류
- 도구 즐겨찾기
- 뽀모도로 집중 타이머
- 오늘 챙길 일
- 금액 한글 변환
- 빠른 메모
